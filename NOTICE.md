## Artwork provenance

According to the maintainer, the sprite artwork was generated in Codex using
[this Pinterest pin](https://ru.pinterest.com/pin/94575660922658789/) as a
visual reference. The pin shows a bust-length depiction of the character. The
remaining body was generated, and the resulting artwork was animated in Codex.
The pin identifies the page where the reference was found; it does not verify
the original artist, the pin uploader's authorship, or a license for reuse.

This records the creation process; it does not establish permission to use the
reference image or grant rights to the underlying character. No clearance from
the reference artist or character rights holder is documented in this repository.
